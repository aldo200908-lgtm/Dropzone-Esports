    DISEÑADO TAMBIÉN PARA EL ORGANIZADOR

    CONTROLAR CADA PAGO.

    Un panel privado permitirá verificar pagos, administrar reembolsos, detectar duplicados y confirmar cupos. Por ahora es un esquema de funcionamiento, no datos de usuarios reales.

    01ORDEN PENDIENTE

    Se registra el torneo, el usuario, el importe y el método.

    02PAGO VERIFICADO

    La pasarela o un administrador autorizado valida el dinero recibido.

    03CUPO CONFIRMADO

    Solo entonces Supabase puede habilitar la inscripción del jugador.

    04RESULTADOS Y REEMBOLSOS

    Se registra el pago de premios o la devolución si corresponde.

    IMPORTANTE

    Las inscripciones de pago con premios requieren revisar la normativa, las políticas de Free Fire y la aceptación de la pasarela para torneos competitivos. También hace falta un titular comercial habilitado. Nada de esto está activado públicamente todavía.
